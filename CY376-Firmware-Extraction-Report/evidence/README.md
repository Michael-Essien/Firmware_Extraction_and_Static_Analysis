# Evidence

This folder is intentionally empty in this template. It's where your **real**
terminal screenshots go after you run `scripts/run_analysis.sh` yourself.

Do not copy the placeholder graphics from `docs/report/assets/placeholders/`
into this folder — those are formatting placeholders used to lay out the
report, not evidence, and are clearly labelled as such.

## Naming convention (matches the report's figure numbers)

| File to add                | Corresponds to |
|-----------------------------|-----------------|
| `01_download.png`           | Report Figure 4 |
| `02_binwalk_scan.png`       | Report Figure 5 |
| `03_binwalk_extract.png`    | Report Figure 6 |
| `04_rootfs.png`             | Report Figure 7 |
| `05_credentials.png`        | Report Figure 8 |
| `06_firmwalker.png`         | Report Figure 9 |
| `firmwalker_report.txt`     | Appendix B      |

Crop each screenshot to the terminal window only (no desktop, no other
windows) before saving, per the course formatting guidelines. Then replace
the matching placeholder image in the report (both the `.docx` and, if you
rebuild it, the `.pdf`) with your real screenshot.
